## prompt 1: my-length

Following skills/scheme-dev/SKILL.md, write my-length in code/77_q4.rkt. It returns the number of top-level elements of a list (a sublist counts as one element, () has length 0). length isn't allowed, so do it by hand, and make it tail recursive since the hidden tests use lists with 10,000 elements. Only this function for now.


## prompt 2: my-map

Now write my-map in code/77_q4.rkt: (my-map f lst) gives a new list with f applied to each top-level element of lst, keeping the order. map and reverse are both forbidden, so if you need to reverse write your own helper. It should also work on long lists (10,000 elements) without trouble.
