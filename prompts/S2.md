# Prompts for S2

Prompts used for this problem, copied word for word, in order.


## prompt 1: my-length

Following skills/scheme-dev/SKILL.md, write my-length in code/77_q4.rkt. It returns the number of top-level elements of a list (a sublist counts as one element, () has length 0). length isn't allowed, so do it by hand, and make it tail recursive since the hidden tests use lists with 10,000 elements. Only this function for now.


## prompt 2: my-map

Now write my-map in code/77_q4.rkt: (my-map f lst) gives a new list with f applied to each top-level element of lst, keeping the order. map and reverse are both forbidden, so if you need to reverse write your own helper. It should also work on long lists (10,000 elements) without trouble.


## prompt 3: insert-if-short

Using my-length and my-map, write (insert-if-short x lst n) in code/77_q4.rkt. It puts x at the front of every list whose length is less than n, at every level of nesting, and the top-level list counts too. The length has to be measured on the original list before inserting anything. () has length 0 so it becomes (x) when n > 0. Elements are atoms or lists, no dotted pairs. Examples: x=42, lst=((1 2) (3 4 5) (6) ()), n=3 gives ((42 1 2) (3 4 5) (42 6) (42)); x=0, lst=(((1) 2) (3) ((4 5 6) ())), n=3 gives ((0 (0 1) 2) (0 3) (0 (4 5 6) (0))); 7 () 3 gives (7) and 7 () 0 gives ().


## prompt 4: print-insert-result

Add print-insert-result to code/77_q4.rkt. It takes no arguments, reads x, lst and n from standard input with read (in that order), and displays the result of insert-if-short followed by a newline. No prompt or any other text. For the input 42 ((1 2) (3 4 5) (6) ()) 3 it should print ((42 1 2) (3 4 5) (42 6) (42)).


## prompt 5: make-inserter

Write a higher-order function (make-inserter x len-ok?) in code/77_q4.rkt. It returns a function of one argument, a list, that inserts x at the front of every list at every level of nesting whose length satisfies len-ok? (len-ok? takes one number). It should still use my-length and my-map. Then change insert-if-short so it's defined using make-inserter. The file must end up with only one insert-if-short, the one that uses make-inserter, and all the earlier examples should still give the same output.


## prompt 6: tests

Write tests/test_q4.rkt with rackunit, the same way as tests/test_q3.rkt (reach the functions without adding provide). Test print-insert-result by feeding it the four example inputs from the assignment as standard input and checking the exact printed output. Also test my-length, my-map and make-inserter on their own, and add edge cases: n = 0, n = 1, empty lists inside lists, symbols, a list exactly as long as n, nesting depth 100 and a list of 10,000 elements. Also check the file has only one insert-if-short. It should run with raco test tests/test_q4.rkt.
