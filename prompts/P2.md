# Prompts for P2

Prompts used for this problem, copied word for word, in order.


## prompt 1: splitting the list

Following skills/prolog-dev/SKILL.md, write split_list(List, Left, Right) in code/77_q2.pl: on backtracking it gives every way to split List into two non-empty parts, keeping the original order.


## prompt 2: expression tree

In code/77_q2.pl, write expr(Nums, Tree, Value). On backtracking it gives every expression tree over Nums (all numbers used once, in order, no joining of digits) built from binary +, -, *, /, together with its integer value. Represent trees as terms (for example num(N), op(Op, L, R)). Allow division only when the divisor is non-zero and the division is exact, at every node. Fail for [].


## prompt 3: printing

In code/77_q2.pl, write tree_string(Tree, String), which turns a tree into an SWI-Prolog string with no spaces using these rules: * and / bind tighter than + and -; operators are left-associative; a left operand is in parentheses only if its top operator has lower precedence than its parent's; a right operand is in parentheses if its top operator has the same or lower precedence; a number is never in parentheses. Examples: (4+2)3, 4+23, 8/42, 8/(42), 1-2-3, 1-(2-3), 1+(2+3), 1+2+3. Do not parse strings back into terms.


## prompt 4: one equation

In code/77_q2.pl, write generate_equation(List, Equation) using split_list, expr and tree_string. Equation is a string "L=R" where both sides have the same value. It must fail (not loop or throw an error) when no equation exists, including for lists of length 0 or 1.


## prompt 5: all equations

In code/77_q2.pl, write all_equations(List, Equations), which returns all valid equations without duplicates, sorted with sort/2 ([] if there are none), and count_equations(List, N), which gives the length of that list. 


## prompt 6: tests

Write tests/test_q2.pl using plunit that loads ../code/77_q2.pl and checks all the examples from the spec ([4,2,5,3] gives 7 equations, [2,3,4] gives [], [2,4,8] gives ["2*4=8"]), plus these edge cases: [], [5], [0,0], division by zero, inexact division, and that every result is a string.


## prompt 7: review

Review code/77_q2.pl against the P2 specification and skills/prolog-dev/SKILL.md. List problems only.
