# Prompts for P1

Prompts used for this problem, copied word for word, in order.

## prompt 1: clues

Following skills/prolog-dev/SKILL.md, write clue/2 for clues 1 to 8 in code/77_q1.pl. A solution is a list [p('Alex',D1,L1,P1), p('Ben',D2,L2,P2), p('Carla',D3,L3,P3), p('Dana',D4,L4,P4)] with values from research/development/design/testing, python/java/'c++'/javascript, 'AI'/web/embedded/data. clue(N, Solution) must succeed exactly when clue N holds on a fully filled-in solution. Write one clause per clue. The clues are:
1. The friend who prefers the AI project does not work in research and is not Dana.
2. Alex does not work in development and does not prefer C++.
3. The friend working in the testing department likes Python.
4. Ben prefers web projects and does not work in testing.
5. The friend whose favorite language is Java works in the design department.
6. Carla's project preference is not embedded, and her department is not development.
7. Dana's favorite language is not Java, and she works in research or testing.
8. The friend who prefers data projects works in research and does not use JavaScript.


## promtpt 2: generator

In code/77_q1.pl, write candidate/1, which generates every fully filled-in solution (Alex, Ben, Carla, Dana in that order) using permutation/2 over the departments, languages and projects. It must not apply any clues.


## prompt 3: main

In code/77_q1.pl, write main/0. It finds one candidate that satisfies clues 1 to 8 (without hard-coding the answer) and prints exactly four lines in the format Alex = [research, python, AI], in the order Alex, Ben, Carla, Dana, with nothing else printed.


## prompt 4: counting

In code/77_q1.pl, write count_solutions(Active, N): N is the number of candidates that satisfy every clue whose number is in Active, ignoring all other clues. Use findall/3 or aggregate_all/3.
