# Prompts for S1

Prompts used for this problem, copied word for word, in order.


## prompt 1: traversal lists

Following skills/scheme-dev/SKILL.md, write inorder, preorder and postorder in code/77_q3.rkt. Each takes a binary tree, which is either () or (value left right), and returns the list of its values in that order (left subtree always before right). Don't use append or reverse, they're not allowed; use an accumulator so the list comes out in the right order. Just these three functions and their helpers, nothing that prints yet.


## prompt 2: printing the traversals

Now add print-inorder and print-all-traversals to code/77_q3.rkt using the traversal functions you wrote. print-inorder displays the inorder list on one line. print-all-traversals displays three lines: inorder, preorder, postorder. Use only display and newline, and every function has to end its output with a newline. For t1 = (4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ()))) it should print (1 2 3 4 5 6 7), then (4 2 1 3 6 5 7) and (1 3 2 5 7 6 4). For the empty tree every line is ().


## prompt 3: height and leaves

Add print-height-and-leaves to code/77_q3.rkt. It prints one line, the list (height leaf-count), followed by a newline. Height of () is 0 and a node is 1 + the max of its two subtrees' heights. A leaf is a node with both subtrees (), and the empty tree has no leaves. Write height and count-leaves as separate helpers first. Expected: t1 gives (3 4), (1 () (2 () (3 () ()))) gives (3 1), (a (b () ()) (c () ())) gives (2 2), and () gives (0 0).


## prompt 4: tests

Write tests/test_q3.rkt with rackunit, set up the way the skill file says (no provide in the solution). Check the exact printed output of print-inorder, print-all-traversals and print-height-and-leaves for all the examples in the assignment (t1, t2, t3 and the empty tree), and add some edge cases of your own: a single node, a tree that only goes left, an unbalanced tree, symbol values, and a deep tree so we know it doesn't blow up. It should run with raco test tests/test_q3.rkt.
